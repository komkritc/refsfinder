## 📖 เกี่ยวกับโปรแกรม

OpenAlex Paper Fetcher เป็นเครื่องมือ GUI ที่ใช้สำหรับค้นหาและดาวน์โหลดข้อมูลบทความวิชาการจากฐานข้อมูล [OpenAlex](https://openalex.org/) โดยสามารถกรองข้อมูลตามปีที่ตีพิมพ์ และเลือกได้เฉพาะบทความที่มีบทคัดย่อ (Abstract) เท่านั้น

โปรแกรมนี้ถูกออกแบบมาเพื่อช่วยนักวิจัยและนักวิชาการในการรวบรวมและจัดการเอกสารอ้างอิงสำหรับงานวิจัย โดยมีฟีเจอร์ที่ทันสมัยและใช้งานง่าย

## ✨ คุณสมบัติเด่น

### 🔍 การค้นหาและกรองข้อมูล
- **ค้นหาบทความ** ด้วยคำสำคัญหลายคำ (ทีละบรรทัด)
- **กรองตามช่วงปีที่ตีพิมพ์** (ค.ศ. 1900-2026)
- **กรองเฉพาะบทความที่มีบทคัดย่อ** (Abstract) เพื่อคุณภาพที่ดีขึ้น

### 🎨 การแสดงผล
- **รองรับธีมสีสว่าง/สีมืด** (Light/Dark Theme) ปรับเปลี่ยนได้ง่าย
- **แสดงความคืบหน้าแบบ Real-time** ขณะดาวน์โหลดข้อมูล
- **หน้าต่างแสดงผลแบบการ์ด** (Paper Explorer) สวยงาม ทันสมัย

### 📂 การจัดการไฟล์
- **เลือกโฟลเดอร์ปลายทาง** ได้เอง
- **เปิดโฟลเดอร์** ได้ด้วยปุ่มเดียว
- **บันทึกข้อมูลในหลายรูปแบบ** (BibTeX, JSON, Excel, Markdown)

### 🗑️ การจัดการเอกสาร
- **ลบเอกสารที่ไม่ต้องการ** ออกจากคอลเลกชัน
- **บันทึกการเปลี่ยนแปลง** และสร้างไฟล์ใหม่โดยอัตโนมัติ
- **โหลดเอกสารจาก JSON** เมื่อเปิดโปรแกรมใหม่

### 🔎 BibTeX Validator / ตรวจสอบเอกสารอ้างอิง (ใหม่!)
- **ตรวจสอบไฟล์ `.bib` ที่มีอยู่แล้ว** ไม่ว่าจะมาจากโปรแกรมนี้หรือแหล่งอื่น ทำงานแยกอิสระจากระบบค้นหา OpenAlex
- **ยืนยันว่าแต่ละรายการอ้างอิงมีอยู่จริง** โดยตรวจสอบกับ Crossref และ OpenAlex (ไม่ใช่แค่เช็กรูปแบบ DOI)
- **เปรียบเทียบข้อมูลเมตา** (ชื่อเรื่อง ผู้แต่ง ปี วารสาร DOI) อย่างโปร่งใส พร้อมคะแนนความเหมือนและคำอธิบายเหตุผล
- **สถานะการตรวจสอบที่ชัดเจน** เช่น `VALID`, `VALID - minor metadata difference`, `DOI VALID - metadata mismatch`, `DOI NOT FOUND`, `PAPER NOT FOUND`, `POSSIBLE DUPLICATE`, `SUSPICIOUS`, `UNVERIFIED`
- **ตรวจจับรายการอ้างอิงที่ซ้ำกัน** จาก DOI, ชื่อเรื่อง, หรือชื่อเรื่อง+ปี+ผู้แต่งคนแรก
- **แก้ไขข้อมูลเมตาอัตโนมัติ** เฉพาะรายการที่พบข้อมูลอ้างอิงที่เชื่อถือได้เท่านั้น (ไม่แก้ไขไฟล์ต้นฉบับ)
- **ลบรายการที่ไม่ถูกต้อง/ซ้ำซ้อน** ได้ทีละรายการหรือลบทั้งหมดที่ไม่ผ่านการตรวจสอบ (มีการยืนยันก่อนลบเสมอ)
- **ส่งออกรายงานผลการตรวจสอบ** เป็นไฟล์ CSV/Excel เพื่อใช้ตรวจทานก่อนส่งบทความตีพิมพ์
- **ทำงานเบื้องหลัง (Background Worker)** พร้อม retry, rate limiting, แถบความคืบหน้า และแคชผลลัพธ์ระหว่างเซสชัน รองรับไฟล์ที่มีรายการอ้างอิงจำนวนมาก
- **ไฟล์ต้นฉบับจะไม่ถูกแก้ไขโดยอัตโนมัติเด็ดขาด** ผลลัพธ์ทั้งหมดจะถูกบันทึกเป็นไฟล์ใหม่ เช่น `refs_validated.bib`

## 📁 ไฟล์ที่สร้างขึ้น

| ไฟล์ | คำอธิบาย |
|------|----------|
| `refs.bib` | บรรณานุกรมแบบสะอาดสำหรับ Overleaf/LaTeX |
| `refs_abstract.bib` | บรรณานุกรมพร้อมบทคัดย่อเต็ม |
| `refs_full.bib` | ข้อมูลครบถ้วนพร้อมบทคัดย่อและคำสำคัญ |
| `refs_with_summary.bib` | บรรณานุกรมพร้อมบทสรุปที่สร้างโดย AI สำหรับ Aider |
| `papers.json` | ข้อมูลเมตาครบถ้วนจาก OpenAlex |
| `papers.xlsx` | สเปรดชีตสำหรับกรองและจัดเรียงข้อมูล |
| `abstracts.md` | บันทึกบทคัดย่อสำหรับการทบทวนวรรณกรรม |

> 💡 เมื่อใช้ฟีเจอร์ **BibTeX Validator** โปรแกรมจะสร้างไฟล์ใหม่แยกต่างหาก เช่น `*_validated.bib` (บรรณานุกรมที่ตรวจสอบ/แก้ไขแล้ว) และ `*_validation_report.csv` หรือ `.xlsx` (รายงานผลการตรวจสอบ) โดยจะไม่แก้ไขไฟล์ `.bib` ต้นฉบับโดยเด็ดขาด

## 🚀 วิธีติดตั้งและใช้งาน

### ความต้องการของระบบ
- Python 3.8 หรือสูงกว่า
- pip (ตัวจัดการแพ็คเกจ Python)

### ขั้นตอนการติดตั้ง

```bash
# 1. Clone repository
git clone https://github.com/komkritc/refsfinder.git
cd refsfinder

# 2. สร้าง Virtual Environment (แนะนำ)
python -m venv venv
source venv/bin/activate  # Linux/Mac
# หรือ
venv\Scripts\activate     # Windows

# 3. ติดตั้ง dependencies
pip install -r requirements.txt

# 4. รันโปรแกรม
python mainGUI.py
```

## 🔎 วิธีใช้งาน BibTeX Validator (ตรวจสอบเอกสารอ้างอิง)

ฟีเจอร์นี้เหมาะสำหรับตรวจสอบไฟล์ `.bib` ก่อนส่งบทความตีพิมพ์ เพื่อกรองรายการอ้างอิงที่ปลอมหรือไม่ถูกต้องก่อนส่งตีพิมพ์

### ขั้นตอนการใช้งาน

1. เปิดโปรแกรม แล้วกดปุ่ม **"🔎 Check BibTeX References"** ที่หน้าหลัก
2. เลือกไฟล์ `.bib` ที่ต้องการตรวจสอบจากหน้าต่างเลือกไฟล์
3. หน้าต่าง **BibTeX Reference Checker** จะเปิดขึ้น พร้อมรายการอ้างอิงทั้งหมดที่พบในไฟล์
4. กดปุ่ม **"🚀 Start Validation"** เพื่อเริ่มตรวจสอบกับ Crossref/OpenAlex แบบเบื้องหลัง (มีแถบความคืบหน้าและสามารถกด **"⏹️ Stop"** ได้ทุกเมื่อ)
5. ดูสถานะการตรวจสอบของแต่ละรายการในตาราง รวมถึงคะแนนความเหมือนและคำอธิบายเหตุผล
6. ใช้ช่องค้นหาหรือตัวกรองสถานะด้านบนเพื่อค้นหารายการที่ต้องการได้อย่างรวดเร็ว

### การแก้ไขและลบรายการ

| ปุ่ม | หน้าที่ |
|------|-------|
| 🛠️ **Fix References** | แก้ไขข้อมูลเมตา (ชื่อเรื่อง, ผู้แต่ง, วารสาร, ปี, DOI และอื่น ๆ) โดยอัตโนมัติ เฉพาะรายการที่มีข้อมูลอ้างอิงที่เชื่อถือได้ |
| 🗑️ **Remove Selected** | ลบรายการที่เลือกไว้ในตาราง (มีการยืนยันก่อนลบ) |
| 🚫 **Remove All Invalid** | ลบรายการทั้งหมดที่มีสถานะ `DOI NOT FOUND` หรือ `PAPER NOT FOUND` (มีการยืนยันก่อนลบ) |
| 📊 **Export Report** | ส่งออกรายงานผลการตรวจสอบเป็น CSV หรือ Excel |
| 💾 **Save Validated BibTeX** | บันทึกรายการอ้างอิงทั้งหมด (รวมส่วนที่แก้ไขแล้ว) เป็นไฟล์ `.bib` ใหม่ |

> ⚠️ **ข้อสำคัญ:** การตรวจสอบใช้เกณฑ์การเทียบข้อมูลแบบระมัดระวัง รายการที่ไม่พบข้อมูลยืนยันเพียงพอ จะถูกระบุเป็น `UNVERIFIED` แทนที่จะระบุว่า "ปลอม/ไม่ถูกต้อง" โดยทันที จะใช้สถานะ `INVALID`/`SUSPICIOUS` เมื่อมีหลักฐานชัดเจนเท่านั้น **ไฟล์ `.bib` ต้นฉบับจะไม่ถูกแก้ไขโดยอัตโนมัติเด็ดขาด**
